# v3 原生界面移植（2026-11-02）

版本：0.7.7-zh.10.v3，沿用本地 zh.8 出生点修复，不升级上游内核。

最终设计来源是用户“v3 第二轮”输入：4a 提供启动器、data.js 与贴图索引，4b 提供图片，6 号 M 菜单更新覆盖早先 ingame.html。旧 v1/v2/v4 不参与当前实现。

## 已写入原生代码

- 共享暖白/青绿配色、四卡片启动器、14px 圆角、超椭圆按钮、原有真实命令和状态检查。
- 启动器继续使用 ImGui/D3D11；星球由独立 HLSL 渲染到逐天体缓存纹理，WIC 从本地目录解码图片。没有浏览器运行时，也没有桌面抓取。
- 史坦顿系统的透视、yaw/pitch、惯性、复位、缩放；球面旋转、标签点击、弧光星昼夜贴图和侧光。解析导数覆盖处理球体边缘，未全局启用多倍采样。
- 仅 4 个主城和 5 个史坦顿空间站可从此地图选择；空白球面点击不会创建地表出生请求。底层三系统目录保留，游戏仍可使用原有多星系功能。
- 地点显示到原生 ID 的映射使用现有目录，不将网页示例经纬度写回游戏配置。5 个空间站继续显示“未实测”。
- M 菜单使用最终青绿胶囊页签、16px 圆角、半透明面板、真实注册页签与可滚动内容。原来的高级生成、删除、船员、装备、任务、玩家与 42 中队等功能继续保留。
- 菜单打开淡入、按钮/页面过渡、关闭淡出与原生窗口位置记忆。支持 DirectComposition 时使用预乘 alpha；Windows 接受背景材料请求时由系统合成背景，效果须实机确认。系统不支持时使用透明或实色回退，不伪造游戏背景，不抓取桌面。
- 网页中的固定示例船表、点击即报成功、2.2 秒跃迁进度及无实际后端的演示设置，没有作为真实功能移入。仍由原有服务/队列反馈操作状态。

## 用户自行验证的重点

从独立新版目录打开启动器，检查四卡片、星图旋转/缩放、9 地点保存与重新打开后的显示；进入游戏后按 M，检查页签、搜索、拖动、真实功能和透明背景。具体反馈与日志再用于修复。未验证的空间站不得据本次构建标记为已验证。

现用 zh.7、zh.8 安装和原快捷方式保持原样。新构建和本机资源只放在独立输出目录，备份路径写入该目录的 LOCAL-INSTALL.json。
